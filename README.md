# FitLegend — Web

Sitio web oficial de **FitLegend**, la aplicación móvil de fitness con gamificación disponible en Google Play.

🌐 [fitlegend-legal](https://ismape2302.github.io/fitlegend-legal/)
📱 [Descargar en Google Play](https://play.google.com/store/apps/details?id=com.impapps.fitlegend)

---

## Descripción

Landing page oficial de FitLegend desarrollada en HTML, CSS y JavaScript puro, alojada en GitHub Pages. Presenta las funcionalidades de la aplicación, capturas de pantalla reales, estadísticas de uso y testimonios de usuarios.

## Características de la web

- Fondo animado con partículas interactivas
- Strip de capturas de pantalla con scroll horizontal táctil en móvil
- Lightbox para ampliar imágenes al pulsar
- Animaciones de scroll bidireccionales
- Sección de estadísticas, features y testimonios
- Diseño responsive (móvil, tablet y escritorio)
- Links a política de privacidad y eliminación de cuenta
