🛡️ Política de Privacidad - FitLegend

Última actualización: 20 de marzo de 2026

ImpApps Studio opera la aplicación FitLegend. Esta página informa sobre nuestra política de recogida, uso y divulgación de datos personales.

Datos que recogemos

  • Nombre y dirección de correo electrónico
  • ID de usuario generado por Firebase
  • Datos de actividad física (pasos, calorías, entrenamientos)
  • Ubicación GPS (solo durante el uso de rutas, opcional)
  • Mensajes del chat entre usuarios
  • Foto de perfil (opcional)
  • ID del dispositivo para notificaciones push
  • Registros de fallos de la aplicación

Cómo usamos los datos

  • Para proporcionar y mejorar las funciones de la app
  • Para autenticar usuarios y gestionar cuentas
  • Para enviar notificaciones push
  • Para mostrar estadísticas y progreso personal
  • Para el ranking y funciones sociales

Terceros

Utilizamos los siguientes servicios de terceros:

  • Firebase (Google) — autenticación, base de datos y notificaciones
  • Google Maps — rutas GPS
  • ExerciseDB — biblioteca de ejercicios
  • Anthropic Claude — coach de IA

Eliminación de datos

Puedes eliminar tu cuenta y todos tus datos desde la app en Perfil → Ajustes → Eliminar cuenta. La eliminación es inmediata y permanente.

Seguridad

Todos los datos se transmiten cifrados mediante HTTPS/TLS. Los datos se almacenan en Firebase con las medidas de seguridad de Google Cloud.
